
# Superstore Sales Analysis

## Overview
Analysis of sales, profit, and discount impact using Superstore dataset.

## Tools
- Python (Pandas, Matplotlib)
- BigQuery
- Google Sheets

## Key Insights
- Sales increasing over time
- Strong seasonality (Q4 peaks)
- High discounts reduce profit
- Furniture category underperforms
- Few products cause major losses

## Structure
- data/ → dataset
- scripts/ → python analysis
- visuals/ → charts
